# A-Basic-Calculator

A simple, interactive calculator that allows users to perform basic arithmetic operations with additional features such as dark mode, keyboard support, and more.

#Features

1.Basic Arithmetic: Perform addition, subtraction, multiplication, and division.

2.Dark/Light Mode Toggle: Switch between dark and light mode for a better user experience.

3.Click Sound: Enjoy a clicking sound for each key press, making the interaction more engaging.

4.Keyboard Support: Use your keyboard to perform calculations instead of clicking on buttons.

5.Tooltips: Hover over buttons to see a brief description of each operator.

6.Scientific Mode (Upcoming): Toggle to scientific mode for more advanced mathematical operations.


##How to Use

1. Open the calculator in your browser.
2. Use the on-screen buttons or your keyboard to input numbers and perform operations.
3. The result will be displayed after each operation.
4. Hover over any button to see what it does before clicking.
5. Toggle between light and dark mode using the mode button.
6. Keyboard Support: You can use the following keys for basic operations:
    Numbers: 0-9
    Operators: +, -, *, /, %
    You can also use the Enter key to calculate the result and Esc to clear the display.

##Technologies Used
HTML: Structuring the content of the calculator.
CSS: Styling the layout and design of the calculator.
JavaScript: Implementing the functionality and features such as the click sound, keyboard support, and dark mode toggle.
